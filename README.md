# Integrated Project Monitoring Platform (SIH26103 Prototype)

AI-augmented layer on top of PAIMANA-style project monitoring: predicts delay,
cost overrun, and a live risk score for infrastructure projects, with an
explainable dashboard and a simple query assistant.

## What's inside

```
backend/
  dataset.csv          -> synthetic dataset (1200 projects, grounded in MoSPI stats)
  train_model.py        -> trains the 3 ML models (delay, cost overrun, risk)
  main.py                -> FastAPI backend (API + serves the dashboard)
  models/                -> trained .pkl models (generated by train_model.py)
  static/index.html      -> dashboard frontend (vanilla JS + Chart.js)
requirements.txt
```

## Roles & Login (NEW)

The platform now has 4 access levels, matching real PAIMANA governance:

| Role | Who | Sees | Can do |
|---|---|---|---|
| **Government Official** (Minister/Project Manager) | logs in with Employee ID | Only projects in their assigned **state** | Send messages to agencies, use scoped AI assistant |
| **Agency** | logs in with Agency ID | All their agency's projects, across states | View reports/messages from officials, message contractors, use Risk Predictor + AI |
| **Contractor** | logs in with Contractor ID | Only their own project(s) | Predict risk, submit delay updates, message-restricted AI (own project only) |
| **Public** | no login needed | Aggregate stats only (counts, sector distribution, cost overview) | Cannot see individual project details, delay reasons, or use the AI assistant |

### Database

User accounts, messages, and contractor delay-update reports are stored in a
real **SQLite database** (`backend/paimana.db`), separate from the project
analytics data (`dataset.csv`, used by the ML models). This file is created
and seeded automatically the first time you start the server — delete it if
you ever want to reset all accounts/messages back to the demo defaults.

### Messaging flow

- **Official → Agency**: officials can send a message about a specific project
  to that project's implementing agency (e.g. "please complete on time").
- **Agency → Contractor**: agencies can message the contractor working on a
  project.
- **Contractor → Report Delay Update**: contractors submit status/delay
  reports tied to their project, visible in their own history.
- The **AI voice assistant can also send messages for you** — e.g. as an
  official, just say "send a message to the agency for project PRJ00157 to
  complete on time" and it sends it directly, no form needed.

### Dataset note

The dataset (1,981 projects, 17 ministries, 22 sectors, ~₹37.13 lakh crore
original cost / ₹42.78 lakh crore revised cost / ₹20.36 lakh crore cumulative
expenditure) is calibrated to match the **official figures stated in the
SIH26103 problem statement** (as of April 2026), so the dashboard's headline
numbers line up with what judges have already read in the PS document.

## How to run (one time setup)

```bash
cd backend
pip install -r ../requirements.txt      # or: pip install fastapi uvicorn scikit-learn pandas joblib python-multipart anthropic
python3 train_model.py                   # trains and saves models (only needed once, or after dataset changes)
uvicorn main:app --reload --port 8000
```

Then open **http://localhost:8000** in your browser (use Chrome or Edge for voice features).

## Enabling the AI Voice Assistant (Ask Assistant tab)

The "Ask Assistant" tab uses a real LLM (via NVIDIA NIM, Llama 3.3 70B) so it
can answer open-ended questions about the dataset, not just fixed patterns.
To enable it:

1. Get a free API key from **build.nvidia.com** (sign up → generate an API key;
   new accounts get free inference credits).
2. Open `backend/api_key.txt` and replace the placeholder text with your key
   (just the key, nothing else, no quotes).
3. Restart the server (`uvicorn main:app --reload --port 8000`).

Without a key, the tab still works but shows a message saying the AI isn't
configured yet — everything else in the dashboard works normally regardless.

**Voice notes:**
- Click the mic button, speak your question, and it's transcribed automatically
  (uses the browser's built-in speech recognition — works best in Chrome/Edge,
  needs internet for the speech-to-text step itself).
- The answer is both shown as text and spoken aloud (text-to-speech runs fully
  in the browser, no internet needed for that part).
- Uncheck "Speak replies aloud" if you just want text answers.
- If it can't answer from the dataset, it says so honestly instead of guessing.

## What it does

- **Overview tab**: total projects, % delayed, % cost overrun, high-risk count,
  risk-by-sector chart, risk distribution, and model feature-importance chart
  (explainability — shows *why* the model flags risk).
- **Projects tab**: full project register with filters (sector, state, risk, status).
- **Predict Risk tab**: enter a new/hypothetical project's parameters (cost,
  duration, progress, fund utilization, milestones) and get a live prediction:
  delay in months, cost overrun %, revised cost, risk label + reasons.
- **Ask Assistant tab**: simple natural-language query interface over the
  project data (rule-based for the prototype; swap in an LLM + RAG for the
  final build if time permits).
